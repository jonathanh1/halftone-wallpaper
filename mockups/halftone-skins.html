Simulated workbench: chats, files and checks are fake; nothing runs. Field rendered live by _halftone.js on a canvas behind CSS backdrop-filter panes.

All candidates · measured on the frozen frame (t = 4.2 s)

Method: each field is drawn frozen at t = 4.2 s, read back with getImageData, downsampled to 8 px cells and box-averaged over ±σ of each pane's blur (a box this narrow overstates peaks, so the floors are conservative), saturated with the CSS saturate() matrix, then composited under the pane fill. Ink contrast is WCAG 2.x against that worst cell. Moving frames can briefly exceed the frozen peak — see the verdicts.
